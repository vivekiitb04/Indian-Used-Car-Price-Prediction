# Indian-Used-Car-Price-Prediction
• Analyzed factors such as car age, mileage, fuel type, body style, ownership and location through Exploratory Data Analysis,
identifying key patterns, relationships and pricing trends across different vehicle characteristics and market segments.
• Engineered car age from model year and handled categorical and numerical variables using imputation, one-hot encoding and
standardization through a preprocessing pipeline for subsequent model training and performance evaluation.
• Implemented Linear Regression, Ridge, Lasso, Decision Tree, Random Forest and KNN models, applying GridSearchCV
for hyperparameter tuning and evaluating model performance using R2-score, adj R2, MAE and RMSE across the models.
• Random Forest achieving R² = 0.64, adj R2-score=0.61, MAE = 185,656 and RMSE = 295,194 on the test set, demonstrating
strong predictive performance among the evaluated models.
